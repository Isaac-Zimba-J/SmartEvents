# Report Generation — Design

**Date:** 2026-09-15
**Status:** Approved for implementation

## Goal

Let organizers and company admins download three reports as PDF or Excel:
an event's attendee list, an event's sales/payments summary, and a venue's
booking history. Generation is server-side so output is consistent, covers
the full dataset, and can later be reused for emailed reports.

## Scope

In: the three reports below, PDF + `.xlsx`, download buttons in the Angular
app, role-based access.

Out (v1): date-range filters, company logo image in the PDF, company-wide
summary report, scheduled or emailed reports, CSV.

## API

New `ReportsController` at `api/reports`, `[Authorize]`.

| Endpoint | Roles | Ownership rule |
|---|---|---|
| `GET /events/{eventId}/attendees?format=pdf\|xlsx` | SuperAdmin, CompanyAdmin, Organizer | Organizer: `event.OrganizerId == userId`. CompanyAdmin: `event.Company.Users.Any(u => u.Id == userId)`. SuperAdmin: any. |
| `GET /events/{eventId}/sales?format=pdf\|xlsx` | same | same |
| `GET /venues/{venueId}/bookings?format=pdf\|xlsx` | SuperAdmin, CompanyAdmin | CompanyAdmin: `venue.Company.Users.Any(u => u.Id == userId)`. SuperAdmin: any. |

Responses:

- `200` — `File(bytes, contentType, fileName)` where
  `fileName` is `{report}-{slug}-{yyyyMMdd}.{ext}`, e.g.
  `attendees-dev-summit-2026-20260915.pdf`, `venue-bookings-{SlugHelper.Generate(venue.Name)}-20260915.xlsx` (venues have no stored slug).
  `Content-Disposition` is set so the client can read the name.
- `400 { message }` — unknown `format` (default when omitted: `pdf`).
- `403` — role allowed but ownership rule fails.
- `404 { message }` — event/venue not found.

Ownership filtering follows `AnalyticsController.GetEventStats`. The controller
queries EF, builds the report model, resolves a renderer by format, returns the
bytes. No service layer beyond the renderers (matches the `QrCodeService` precedent).

## Report contents

Shared header on every report: company name, report title, subject line
(event title + date + venue, or venue name + address), `Generated <UTC> by
<First Last>`. Landscape A4. Footer: page `x / y` and "Generated by SmartEvents".

### Attendee list

- Summary: Confirmed · Waitlisted · Checked-in · Capacity (`maxAttendees`).
- Rows: one per registration whose status is not `Cancelled`, sorted by
  last name then first name.
- Columns: `#`, Name, Email, Phone, Ticket #, Status, Registered (UTC
  date + time), Checked-in (time or `—`).

### Sales report

- Summary: Tickets sold (payments with status `Completed`), Gross revenue
  (sum of completed amounts, `K #,##0.00`), Airtel Money count + amount,
  MTN MoMo count + amount, Pending count, Failed count.
- Rows: one per `Payment` on the event, newest first.
- Columns: Date (`CreatedAt`), Attendee, Ticket #, Method, Amount, Status,
  Reference (`TransactionReference` or `—`).
- Free events produce a valid report with zero rows; the UI hides the button
  when `!isTicketed`.

### Venue bookings

- Subject block: venue name, address/city, capacity, price per day.
- Summary: Total bookings, Confirmed, Days booked (sum of `(EndDate -
  StartDate).Days`, min 1, confirmed only), Revenue (sum of `TotalAmount`
  where `PaymentStatus == Completed`).
- Rows: every booking for the venue, newest `StartDate` first.
- Columns: Booked by, Email, Start, End, Days, Status, Payment, Method,
  Amount, Ref (`TransactionRef` or `—`).

## Rendering layer — `SmartEvents.API/Infrastructure/Reports/`

```
Infrastructure/Reports/
├── ReportModels.cs        # ReportHeader, AttendeeReport, SalesReport, VenueBookingsReport (+ row records)
├── IReportRenderer.cs     # Format, ContentType, FileExtension, Render(...) ×3 → byte[]
├── PdfReportRenderer.cs   # QuestPDF 2026.9.0
└── ExcelReportRenderer.cs # ClosedXML 0.105.1
```

- Models are plain positional records in the `SmartEvents.API.Infrastructure.Reports`
  namespace. Renderers depend only on these — never on `SmartEventsDbContext`.
- `IReportRenderer.Format` is `"pdf"` / `"xlsx"`. Both renderers are registered
  as singletons; `ReportsController` injects `IEnumerable<IReportRenderer>` and
  selects with `FirstOrDefault(r => r.Format == format)`.
- PDF: one shared page scaffold (header, footer) used by all three reports;
  tables with a bold header row and zebra striping; amounts right-aligned.
- Excel: workbook with a `Summary` sheet (label/value pairs) and a data sheet
  named after the report; header row bold and frozen; columns auto-fit; amount
  cells use number format `"K "#,##0.00`; dates use `yyyy-mm-dd hh:mm`.
- `Program.cs`: `QuestPDF.Settings.License = LicenseType.Community;` and the
  two `AddSingleton` registrations.

## Frontend

### `core/services/reports.service.ts`

```ts
downloadEventAttendees(eventId: string, format: ReportFormat): Observable<void>
downloadEventSales(eventId: string, format: ReportFormat): Observable<void>
downloadVenueBookings(venueId: string, format: ReportFormat): Observable<void>
```

`ReportFormat = 'pdf' | 'xlsx'` in `core/models/report.models.ts`. Each method
calls `http.get(url, { responseType: 'blob', observe: 'response' })`, reads the
filename from `Content-Disposition` (fallback `report.{ext}`), creates an object
URL, clicks a temporary `<a download>`, and revokes the URL. Because the error
body arrives as a `Blob`, the service converts it to text and extracts
`message` before surfacing it, so callers can keep using `err.error?.message`.

### `core/components/report-download/report-download.component.ts`

Standalone. Inputs: `label: string`, `download: (format: ReportFormat) =>
Observable<void>`. Renders the label plus two buttons ("PDF", "Excel") with
`file-text` / `file-spreadsheet` icons; shows a busy state while a download is
in flight and a toast on error.

### Placement

- **Attendees page** (`features/organizer/attendees`), top bar: *Attendee list*;
  *Sales report* only when `event.isTicketed`.
- **Venue detail** (`features/venues/venue-detail`): *Bookings report*, shown
  only when the current user is `CompanyAdmin` or `SuperAdmin`.

Icons `download`, `file-text`, `file-spreadsheet` are added to
`LucideAngularModule.pick({...})` in `app.config.ts`.

## Error handling

- Renderer exceptions propagate to `ExceptionMiddleware` (500). Nothing is
  written to the database by any report endpoint.
- Frontend: any non-2xx → toast with the server `message` or
  "Report download failed."

## Verification

There is no test project. Verification is:

1. `dotnet build` clean (no new warnings).
2. Run the API; `curl` all three endpoints × both formats as
   `organizer@techevents.co` (own event), `admin@techevents.co`, and
   `attendee@example.com` (expect 403 / role rejection). Check
   `Content-Type`, `Content-Disposition`, and that bytes begin with `%PDF`
   (PDF) or `PK` (xlsx).
3. Open the generated PDFs and inspect layout; open one `.xlsx` and confirm
   sheets, frozen header, formats.
4. `ng build` passes; click each button in the browser once.
