What's wired up

  • EventsService.getRecommended(excludeEventId) → GET /api/events/recommended?excludeEventId=…
  • Section only renders when auth.isAuthenticated() is true and the API returns at least 1 result
  • Cards are routerLink to /events/:slug — clicking one navigates and reloads recommendations for the new event
  • No loading spinner needed — section appears silently after main event content loads
